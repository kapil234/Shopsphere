ShopSphere is a full-featured e-commerce web application designed to provide a seamless online shopping experience.
It offers users an intuitive interface for browsing, purchasing, and managing products with ease.
• Built a full-stack MERN e-commerce platform with product catalog, cart system, and admin dashboard.
• Implemented JWT authentication and bcrypt password encryption for secure login.
• Designed responsive UI using React.js improving user interaction across devices.
• Optimized API calls and implemented lazy loading, reducing page load time by 25% 
• Tech Stack: React.js, Node.js, Express.js, MongoDB, JWT
